How to get a Google app password

  1. Turn on 2-Step Verification for your Google account (Google Authenticator, a phone prompt or SMS). Open 2-Step Verification ↗
  2. Create an app password. Open App passwords ↗, type a name such as "CertDesk" and click Create.
  3. Copy the 16-character code Google shows you and paste it into Google app password. Spaces don't matter.
  4. Click Verify & save. CertDesk signs in to Gmail to check the password before it saves anything.

Google shows the code only once. If you lose it, delete it and create a new one. Don't see App passwords? It only appears when 2-Step Verification is on, and some work or school accounts turn it off.
